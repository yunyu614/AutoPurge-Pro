# AutoPurge Pro 安全加固测试计划

适用基线：v4.4.2 安全加固开发分支

> 本文档是发布前测试清单。静态检查通过不等于 Android 真机行为已验证。测试前先备份模块配置、名单、统计文件和重要用户文件。

## 1. 静态检查

- [ ] 对所有 Shell 入口、守护脚本、Service_Config 脚本执行 `sh -n`。
- [ ] 对 `source/webroot/app.js` 执行 `node --check`。
- [ ] 检查 ZIP 安装包目录结构，确认 module.prop 位于 ZIP 根目录。
- [ ] 检查五个预编译二进制文件未被替换或损坏。

## 2. 清理范围与预览

- [ ] APK 清理关闭时，预览不列出 APK。
- [ ] APK 清理开启时，只列出 FilePaths.conf 中 download 路径下的 APK。
- [ ] download 指向 storage_root 之外时，清理和预览均跳过。
- [ ] download 或文件整理来源/目标路径经过 storage_root 内的符号链接时，清理、预览和扫描/归档均跳过该路径。
- [ ] download 或文件整理来源/目标路径经过 storage_root 内的符号链接时，清理、预览和扫描/归档均跳过该路径。
- [ ] storage_root 指向 /data、/data/adb、/system、/vendor、/proc、/sys 或 /dev 时，文件操作应被阻止。
- [ ] 模块残留清理开启时，只列出当前 AutoPurge-Pro 模块目录中的 .bak/.backup。
- [ ] 其他模块目录、modules_update、service.d、post-fs-data.d 中的备份文件不得被删除。
- [ ] 点击预览后，候选文件仍然存在；预览不得执行删除。
- [ ] 确认预览明确提示 TimingClear/MTClear 闭源目标未包含在预览范围内。

## 3. 并发与任务生命周期

- [ ] 同时触发两次手动清理，第二次应返回 already_running。
- [ ] 同时触发两次扫描/整理，第二个任务不得启动第二个 worker。
- [ ] 正常结束后 PID 文件和锁目录应被清理。
- [ ] 强制终止 worker 后，状态查询应报告异常结束；确认陈旧锁回收不会接管仍在运行的任务。
- [ ] 模拟空锁目录/缺失 PID 文件，系统应 fail-closed，不得启动并发任务。
- [ ] 同时启动两个 interval_daemon，最多只能有一个持有锁并运行。
- [ ] 停止 interval_daemon 后确认 PID/锁清理；模拟 SIGKILL 后确认下次启动能安全回收陈旧锁。

## 4. 统计与日志

- [ ] 清理前后由其他应用写入数据时，不应再使用“文件数 × 固定大小”的估算值。
- [ ] 首页显示的空间指标应理解为 /data 可用空间变化，不应解释为模块独占释放量。
- [ ] Counter 与 Stats.json 写入中断时，不应留下半截文件。
- [ ] 重置统计后 Counter 和 Stats.json 均为零值，历史日志保持不变。
- [ ] Clear.log / History_Files.log 超过 1 MiB 时轮转；清空日志操作同时清除活动日志和 .1 备份。

## 5. 文件整理

- [ ] 成功移动的文件数与 moved 一致。
- [ ] 目标文件重名时自动生成不覆盖原文件的名称。
- [ ] 目标路径在 storage_root 之外时回退到安全默认目录。
- [ ] 目标目录不可写时，任务状态必须报告失败数量，不得无条件显示成功。
- [ ] 扫描/整理临时文件使用独立 PID 名称，任务结束后无残留。

## 6. 配置与兼容性

- [ ] 定时配置存在重复键时，控制端和 interval_daemon 均读取最后一次定义。
- [ ] WebUI 设置修改后，配置文件重复键被归一化为单一键值，断电/中断不留下半截配置。
- [ ] 非法时间/星期字段不得破坏 status JSON。
- [ ] 升级时保留旧配置、黑白名单、MT 规则和历史统计。
- [ ] 分别在 KernelSU、APatch、Magisk 环境验证安装、WebUI、定时服务及卸载。
- [ ] 至少完成一次重启后定时任务恢复测试。

## 7. 发布门槛

以下项目未完成前，不应将开发分支合并或作为正式 Release：

- [x] CI 静态检查通过（Shell 语法、WebUI JavaScript 语法、配置归一化、非破坏性预览及符号链接逃逸回归）。
- [ ] 至少一台 Android 测试设备完成全部 P0 用例。
- [ ] 真实 Root 环境完成并发、重启、停止与异常中断测试。
- [ ] 闭源二进制 Counter 行为得到确认，或明确接受其统计一致性限制。
- [ ] 备份与回滚流程验证通过。
